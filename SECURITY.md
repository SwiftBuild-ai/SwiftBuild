# Security

This is a development bootstrap and has not completed a production security review.

Do not post vulnerabilities, secrets, or private architecture documents in public issues. Before publishing this repository, maintainers must configure GitHub private vulnerability reporting and verify the Security tab provides “Report a vulnerability”. No private email address has been supplied and none is invented here. Until a verified private channel exists, do not send sensitive reports through public channels.

The application validates architecture imports and limits them to 5 MB. Component definitions are declarative; uploaded JavaScript is never executed. Text is rendered as text. Browser drafts are not encrypted and should not contain credentials. No product analytics or remote telemetry is enabled.

Only the latest bootstrap revision receives fixes. Report affected revision, reproduction steps, impact, and a minimal non-sensitive sample through the configured private channel when available.
