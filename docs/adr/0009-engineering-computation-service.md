# 0009 — Isolated engineering computation

Status: accepted.

TypeScript remains authoritative for native documents, semantic validation, capacity simulation, identity, permissions, revisions, and durable storage. Python 3.12 supplies stationary reliability models and numerical sensitivity calculations. It receives explicit computation contracts, never native documents or database credentials. The open-source product uses manual design and contains no AI adoption.

Analysis contracts are separate schema exports. TypeScript generates JSON Schema; pinned tooling generates Python Pydantic models. Both languages consume shared compatibility and canonicalization fixtures. Native format 1.1 and project archive 1.0 remain unchanged; versioned analysis bundles carry historical revision-linked evidence independently.

PostgreSQL stores jobs and attempts through server-core migrations. A separate TypeScript dispatcher claims leased jobs, rechecks admission, runs existing capacity engines in a child process, and calls an authenticated private FastAPI supervisor. The supervisor runs one bounded Python child at a time. Attempt fencing prevents an expired worker from publishing. Cancellation and revoked admission win over completion. No Redis, separate durable Python queue, or competing domain engine is introduced.

Runtime and numerical-model versions, seed, canonical input digest, units, provenance, coverage and assumptions travel with reports. Replay is deterministic within the recorded environment. Cross-platform floating-point results require tolerance; sampling precision is not model accuracy. Interrupted attempts are incomplete. No inferred vendor reliability, outage timeline, or availability guarantee is supported.

Consequences: deployment requires explicit migrations, runtime-role provisioning, an internal computation token, container budgets and worker readiness. Browser-local simulations remain independent. Analysis bundles import as historical data and cannot trigger execution. Executable user extensions remain unsupported.
