# architecture-schema

Runtime validation contracts and static types for native document version 1.1, including scenarios, traffic classes, provenance, distributions, performance profiles, flow policies, targets and assessments. `migrateDocument` explicitly migrates 1.0 without mutating input; parsing/import paths invoke migration at boundaries. Unsupported versions are rejected. Component schema versions remain independent. Serialization preserves JSON-safe metadata. No UI-framework or hosting dependencies. See [native files](../../docs/architecture/native-format.md) for import boundaries and independent format versions.
