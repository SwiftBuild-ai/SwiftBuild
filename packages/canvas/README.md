# canvas

React Flow adapter and per-instance Zustand editor. Workbench mounts a provider with document history and transient selection. StorageAdapter abstracts browser storage. loadDraft preserves invalid drafts, saveDraft validates before writing, and importDocument enforces a 5 MB limit. Changes must pass keyboard and E2E interaction checks.

The catalog is the default sidebar; the tool rail switches to a keyboard-accessible object list. A fresh draft is blank, with an explicit commerce template available. Custom components embed a named definition derived from a validated primitive in the document. Activity reports actual autosaves; workspace settings select theme and engineering detail. Canvas locking changes interaction only and never changes the architecture model.
