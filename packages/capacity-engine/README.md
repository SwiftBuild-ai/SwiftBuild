# capacity-engine

Pure workload estimation, analytical offered-load propagation and seeded discrete-event topology simulation. Public entry points: `estimateScenario`, `analyzeTopology`, `simulateTopology`, `behaviorRegistry` and `importMeasurementsCSV`. Reports carry engine/model versions, canonical input fingerprints, formulas, units, assumptions, provenance, coverage and explicit incomplete states.

See [engineering models](../../docs/engineering/capacity.md) and [measurement formats](../../docs/engineering/measurements.md). Add numerical references before extending behavior. No UI-framework, browser persistence, provider or account dependencies.
